# iOS 示例目录

用于沉淀 iOS ReactorKit 正例和反例。

建议优先补充：

1. Action / Mutation / State 正例。
2. Reactor 调用 KMP UseCase 正例。
3. ViewController 只做绑定正例。
4. weak self 使用正例。
5. ViewController 直接网络请求、直接使用 DTO、展业地硬编码等反例。

示例必须说明：

- 对应业务模块。
- 适用规则。
- 代码路径。
- 为什么是正例或反例。
