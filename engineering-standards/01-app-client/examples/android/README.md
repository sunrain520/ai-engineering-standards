# Android 示例目录

用于沉淀 Android Jetpack MVVM、BaseVM、HSLoadData 正例和反例。

建议优先补充：

1. 复杂页面 ViewModel 正例。
2. UiState 正例。
3. HSLoadData 状态处理正例。
4. Activity / Fragment 轻量化正例。
5. UI 直接网络请求、直接使用 DTO、展业地硬编码等反例。

示例必须说明：

- 对应业务模块。
- 适用规则。
- 代码路径。
