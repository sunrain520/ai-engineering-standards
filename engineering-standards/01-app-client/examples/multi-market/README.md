# 多展业地示例目录

用于沉淀多展业地配置化、策略化和 DI 适配正例。

建议优先补充：

1. 域名配置正例。
2. 语言和主题配置正例。
3. 功能开关正例。
4. DTO Mapper 差异隔离正例。
5. Strategy 或 DI 替换实现正例。
6. 页面层硬编码 KAZ / country 判断反例。

示例必须说明：

- 涉及展业地。
- 配置项。
- 策略或 DI 入口。
- 对应代码路径。
- 为什么是正例或反例。
