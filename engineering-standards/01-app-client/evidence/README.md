# APP Evidence

本目录保存 APP 规范背后的代码事实、正例、反例和历史兼容说明。

## 文件

- `code-facts.md`：代码事实。
- `positive-examples.md`：正例路径和模式。
- `forbidden-examples.md`：反例路径、风险和替代做法。
- `legacy-compatible.md`：历史兼容边界。

## 安全要求

不得写入密钥、token、生产凭据、用户隐私或交易数据原文。
