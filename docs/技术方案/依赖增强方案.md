# 2. 第一阶段最小依赖

第一阶段我建议只引入这些。

## 2.1 系统依赖

| 依赖               | 作用                                     | 是否必须 |
| ---------------- | -------------------------------------- | ---- |
| **Node.js**      | 跑 `.mjs` 脚本、文件扫描、JSON 合同校验、渲染文档        | 必须   |
| **Git**          | 获取 commit、branch、diff、repo root、文件变更历史 | 必须   |
| **Shell / Bash** | 跑验证脚本、wrapper 脚本                       | 必须   |
| **ripgrep / rg** | 高性能搜索代码模式                              | 强烈建议 |
| **jq**           | 调试 JSON 输出                             | 可选   |

最小运行环境：

```bash
node --version
git --version
rg --version
```

---

## 2.2 Node 依赖

建议第一阶段只加少量依赖。

```json
{
  "devDependencies": {
    "ajv": "^8",
    "fast-glob": "^3",
    "gray-matter": "^4",
    "yaml": "^2"
  }
}
```

作用：

| 包             | 作用                                                                    |
| ------------- | --------------------------------------------------------------------- |
| `ajv`         | 校验 `repo-profile.v1`、`code-facts.v1`、`standard-rule.v1` 等 JSON Schema |
| `fast-glob`   | 跨平台文件扫描，替代手写递归                                                        |
| `gray-matter` | 解析 Markdown Front Matter                                              |
| `yaml`        | 读取配置、规则元数据、Skill 输入                                                   |

第一阶段不要急着引入大型 AST 框架，先通过文件扫描、正则、目录结构、命名约定、注解识别，完成最小闭环。

# 4. 各端代码事实抽取依赖

## 4.1 Java 后端

第一阶段最小依赖：

| 依赖          | 作用                                                             | 建议 |
| ----------- | -------------------------------------------------------------- | -- |
| `rg`        | 搜索 `@RestController`、`@Service`、`@Repository`、`@Transactional` | 必须 |
| `fast-glob` | 找 Java / XML / YAML 文件                                         | 必须 |
| Git         | 获取 evidence commit                                             | 必须 |

第一阶段可以通过以下模式抽取：

```text
@RestController
@Controller

@Component
@Repository
@Mapper
@Transactional
@RequestMapping

@PostMapping
@ExceptionHandler
@RestControllerAdvice
```

第二阶段增强依赖：

| 依赖                 | 作用          |

| CodeGraph          | 跨文件调用图、依赖图  |

```text
Phase 1:
  rg + 文件路径 + 注解 + 命名规则

  tree-sitter-java / JavaParser / CodeGraph

  LSP + 调用关系 + 影响面
```

# 15. 我的建议

第一版就按这个依赖组合落地：

```text
必装：
- Node.js
- Git
- ripgrep
- ajv
- fast-glob
- gray-matter
- yaml

先不装：
- CodeWiki
- CodeGraph
- tree-sitter 全家桶
- 向量库
- 图数据库
```
