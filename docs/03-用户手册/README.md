## 快速路径

1. 只想了解项目能做什么：阅读用户手册第 1-3 章。
2. 准备安装或测试 Skill：阅读用户手册第 6 章。
3. 准备从项目代码萃取规范：阅读用户手册第 7 章。
4. 准备用产物指导 AI 编码和 Review：阅读用户手册第 8-9 章。
5. 遇到边界、失败或权限问题：阅读用户手册第 10-12 章。
