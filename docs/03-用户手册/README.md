# 用户手册

本目录面向 `AI Engineering Standards` 的实际使用者，说明如何读取规范资产、如何使用 `project-standard-extractor` 从真实项目萃取团队规范，以及如何把产物用于 AI 辅助研发和 Code Review。

## 当前手册

| 文档 | 适用场景 |
| --- | --- |
| [AI 辅助研发工程规范用户手册](./AI辅助研发工程规范用户手册.md) | 第一次使用本仓库、准备执行规范萃取、需要理解产物和发布边界 |
| [project-standard-extractor 执行逻辑分析](./project-standard-extractor-execution-analysis.md) | 需要上帝视角理解 Skill 触发逻辑、执行流程、阶段产物、ASCII 图和 repair-only 边界 |
| [project-standard-extractor 团队分享稿](./project-standard-extractor-sharing-script.md) | 面向核心研发的 30 分钟分享稿，聚焦 AI 辅助开发、稳定路径、设计取舍和共建试点 |

## 快速路径

1. 只想了解项目能做什么：阅读用户手册第 1-3 章。
2. 需要理解 Skill 内部执行逻辑：阅读执行逻辑分析文档。
3. 准备给团队做介绍：阅读团队分享稿。
4. 准备安装或测试 Skill：阅读用户手册第 6 章。
5. 准备从项目代码萃取规范：阅读用户手册第 7 章。
6. 准备用产物指导 AI 编码和 Review：阅读用户手册第 8-9 章。
7. 遇到边界、失败或权限问题：阅读用户手册第 10-12 章。
